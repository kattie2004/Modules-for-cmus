# Modules-for-cmus
Adds Cava and Htop for Cmus via Tmux

# Caution: 
before use install pkgs:
1. tmux
2. cmus
3. cava
4. htop

# Usage:
for open script run "./cm", and for close script run "tmux kill-server"

# Better exp:
for better experience add alias for your .zshrc OR .bashrc in bottom:

alias for open program:
alias TYPE_HERE_QUICK_SHORTCUT='/path/to/file/cm'

alias for close program:
alias TYPE_HERE_QUICK_SHORTCUT='tmux kill-server'
